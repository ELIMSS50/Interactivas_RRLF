# Interactivas_RRLF

Ejercicios de la materia de Interactivas.

## Contenido

| Carpeta | Descripción |
|---|---|
| `ejercicio1/` | Tienda de electrónica **ElectroShop** con HTML, CSS propio y JavaScript. Sidebar fijo que se comprime, catálogo de productos, reseñas y contacto. |
| `ejercicio2/` | Tarjeta de perfil hecha con **Bootstrap 5**. |
| `ejercicio3/` | El mismo sitio del ejercicio 1, pero maquetado con **Bootstrap 5** en lugar de CSS propio. |

## Cómo verlos

Abrir el archivo `index.html` de la carpeta correspondiente en el navegador.

Los ejercicios 2 y 3 cargan Bootstrap 5.3.3 desde CDN, así que necesitan conexión a internet.
